# Security policy

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/QueenDekim/NetLens/security/advisories/new).
If unavailable, ask for a private contact in an issue without posting sensitive
details.

Provide the affected revision, impact and a reproduction with dummy data. Remove
provider keys, packet captures, process paths and private hostnames from public
logs. Reports can contain personal network activity even when API-key fields are
redacted.

The current release branch receives fixes. Download release artifacts from this
repository, verify their SHA-256 files and review driver downloads on the official
Npcap site. NetLens does not install drivers or change capture-service settings.
